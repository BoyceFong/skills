# 词条文档模板

每个词条文档必须严格遵循以下结构。使用 markdown 格式创建。

## 模板

```markdown
# <词条名称>

## 定义
<一句话定义该实体/概念。必须来自资料，不编造。>

## 关键事实
- <事实1>（来源：<文件名/文章标题>）
- <事实2>（来源：<文件名/文章标题>）
- <事实3>（来源：<文件名/文章标题>）
- 资料中没有的信息：明确写「暂无资料」

## 与其他词条的关系
- [<关联词条1>](https://<tenant>.feishu.cn/docx/<doc_id>)：<具体关系描述>
- [<关联词条2>](https://<tenant>.feishu.cn/docx/<doc_id>)：<具体关系描述>

## 来源
- <来源文件名1>
- <来源文章标题1>
```

## 各部分要求

### 定义
- 一句话，简洁准确。
- 必须来自资料，不得凭记忆编造。
- 如果资料中没有明确定义，基于资料中的描述综合，并标注“基于资料综合”。

### 关键事实
- 每条事实必须标注来源，格式：`（来源：<文件名/文章标题>）`。
- 事实必须来自资料，不得编造。
- 资料中没有的信息，明确写「暂无资料」，不得臆造。
- 数字、日期、参数等精确信息必须回原文核对。
- 每条事实独立成行，用 `- ` 开头。

### 与其他词条的关系
- **必须使用飞书文档双链链接**，格式：`[词条名](https://<tenant>.feishu.cn/docx/<doc_id>)`。
- 不得使用纯文本词条名。
- 每个词条至少链接到 1-2 个已有词条。
- 关系描述必须具体，说明是什么关系：
  - 对比关系：“与XX对比测试中效果更强/更弱”
  - 基于关系：“基于XX技术改进而来”
  - 同属关系：“与XX同属开源大模型”
  - 采用关系：“被XX采用”
  - 产品化关系：“是XX的产品化实现”
- 不得只写“相关”“有关”等模糊描述。
- 被链接的词条必须在其关系部分回链。

### 来源
- 列出所有提供了事实的来源文件名或文章标题。
- 如果是资料卡，写“资料卡：<名称>”。
- 如果是文章，写文章完整标题。

## 创建后检查

- [ ] 定义来自资料，非编造
- [ ] 每条关键事实标注了来源
- [ ] 资料中没有的信息标注了「暂无资料」
- [ ] 关系部分使用了双链链接（非纯文本）
- [ ] 至少链接到 1 个已有词条
- [ ] 关系描述具体（非“相关”）
- [ ] 来源部分列出了所有来源
- [ ] 被链接的已有词条已回链
- [ ] 索引已更新
- [ ] 日志已追加
