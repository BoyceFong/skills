# 入库流程（Ingest）

## 原始资料入库

### 步骤

1. **读取资料**：完整读取用户提供的资料文件（全文，不跳过任何部分）。如果是图片型 PDF，使用视觉读取。
2. **创建资料卡**：在「原始资料」区创建资料卡文档，包含：
   - 来源信息（来源名称、原文链接、收录时间）
   - 核心内容摘要
   - 重要内容明细（按主题分段）
3. **提取词条**：从资料中提取值得沉淀的实体、概念、方法论、产品、公司、人物等。每个提取的词条必须：
   - 有明确的定义（来自资料）
   - 有至少 2 条关键事实（来自资料，标注来源）
   - 与至少 1-2 个已有词条建立双链关系
4. **创建词条文档**：在「词条」区创建每个新词条，使用标准模板（见 `entry-template.md`）。
5. **补全双链**：检查被新词条链接的已有词条，在其「与其他词条的关系」部分回链新词条。
6. **更新索引**：在「索引」文档中加入新资料卡和新词条（按 A-Z 排序，先英文后中文）。
7. **追加日志**：在「更新日志」追加 `ingest` 条目，记录入库了什么。
8. **验证**：列出「词条」区确认数量增加，读取索引确认新条目存在。

### 资料卡模板

```markdown
# 资料卡：<资料名称>

## 来源信息
- 来源：<来源名称>
- 原文链接：<URL>
- 收录时间：<YYYY-MM-DD>
- 数据来源：<如 AIHOT 等>

## 核心内容摘要
<2-3 句话概括资料核心内容>

## 重要内容明细
### 1. <主题1>
- 来源：<具体来源>
- 链接：<URL>
- 摘要：<详细内容>

### 2. <主题2>
...
```

## 文章入库

### 步骤

1. **判断状态**：询问用户或根据内容判断是成稿还是草稿。
2. **清理内容**：去掉视频播放器 UI 文字、关注按钮等无关内容，保留正文。
3. **创建文章文档**：在「我的文章/成稿」或「我的文章/草稿」下创建文档。
4. **提取词条**：从文章中提取有价值的概念/实体/方法论创建词条（词条来源标注文章标题）。
5. **补全双链**：同上。
6. **更新索引**：在「我的文章」区加入新文章，词条区加入新词条。
7. **追加日志**。
8. **验证**。

### 图片型 PDF 处理

如果上传的是图片型 PDF（文本提取为空）：
1. 使用可用的 PDF 渲染工具（如 `pdftoppm`）将 PDF 每页转为图片。
2. 使用 Agent 的视觉读取能力逐页读取。
3. 整理读取结果为结构化文本。
4. 按正常流程入库。

## 入库后的强制检查

- [ ] 每个新词条都有定义、关键事实（标注来源）、双链关系、来源四部分
- [ ] 每个新词条至少链接到 1 个已有词条
- [ ] 被链接的已有词条已回链
- [ ] 索引已更新（A-Z 排序正确）
- [ ] 日志已追加
- [ ] 无孤儿词条产生
