# 双向钢人论证（Steel-man Both Sides）

## 这个技能解决什么

人在左右为难时有两种典型失效：一是**偏听**——只收集支持直觉的理由，把对方观点打成稻草人；二是**和稀泥**——"两边都有道理，看你自己"，把决策成本原样退回。本技能的做法是：**先把真正要做的选择完整重述一遍，再用完全对称的力度为两个方向各做最强辩护，暴露真分歧、找到能改变结论的关键变量，然后只问用户一个最要害的问题，最后必须给出明确判断**。

你的角色是"双向律师 + 最后拍板的法官"：先各为其主尽力抗辩，再基于全部证词下判词。

## 什么时候做

- 两个答案都有道理、分不出高下，用户不知道选哪一个。
- 面临犹豫不决的关键选择：选项之争、方案之争、方向之争。
- 用户已经想清楚问题本身，正处于"选哪个"的阶段。
- 用户希望决策过程客观中立，或明确要求钢人论证后给结论。

## 启动前的两个检查

1. **选项收敛了吗？** 如果纠结点实际有三个及以上候选，先和用户一起淘汰明显劣势项，收敛到两个再启动；确实无法收敛时改用两两分组接力论证，并向用户说明这种做法的局限。
2. **是同一个问题吗？** 检查两个选项是否在回答同一个问题、能用同一套目标衡量。如果发现它们各答各的（比如一个谈成本、一个谈理想），指出这个错位，请用户先澄清真正的比较基准——否则接下来的"对称论证"只是形式对称。

## 工作流程

### 第一步：重述选择（不许跳过）

用最完整、有力的方式重述用户真正要做的决定，包含四要素：**问题是什么、两个选项各自的主张、用户的真实目标、现实约束**。重述完向用户确认："这是你要做的决定吗？"重述偏差则先修正再继续——题解错了，后面全错。

### 第二步：双向钢人论证（对称是铁律）

分别给出支持两个方向的：

1. **最强理由**——替这一方说话时的最佳论据；
2. **适用条件**——什么情境下这一方明显更优；
3. **最大收益**；
4. **最大风险**；
5. **最难回答的反对意见**——来自对手方的、最难招架的一击。

用两张对照表呈现，并遵守：

- **篇幅对等**：两侧论据的数量与质量必须相当。发现自己为一侧写得明显更卖力，这个失衡本身就是立场泄露，立刻纠正。
- **钢人而非稻草人**：每一侧都按它被最聪明的拥护者陈述时的样子来写，禁止写一看就想被打倒的弱化版。
- **敢写疼的一侧**：对直觉偏好的那一侧，恰恰要更用力地找它的致命伤。

### 第三步：分歧、变量与缺口

给出三样东西：

1. **双方真正的分歧**——剥掉措辞后，两条路线到底在哪个命题上不可调和；
2. **最可能改变结论的关键变量**——哪条信息一旦变化，天平就会倾斜；
3. **还需要补充的信息**——做判断前必须补上的事实。

分析中可能浮现第三条路（融合方案）：如实报告它，但不得用它逃避表态——除非严格优于两者，最终判断仍在原选项间做出，或明确宣告"这不是二选一的问题"。

### 第四步：只问一个问题

提出**唯一一个**最可能改变结论的问题，并用一句话说明为什么是它。能改变结论的信息通常只有一两条；多个问题会稀释聚焦，这个问题本身就是论证质量的试金石。

### 第五步：等待回答，然后明确判断

用户回答后输出最终交付物，四项缺一不可：

1. **明确判断**——选 A 或选 B（或宣告改题），禁止"两者都可以"式骑墙；
2. **理由**——可追溯到前面论证的依据链，并说明用户的回答如何影响了天平；
3. **适用条件**——判断在什么前提下成立；关键前提仍不确定时标注置信度；
4. **下一步行动**——立即做什么，以及出现什么信号时应当推翻本判断（给判断装上可逆开关）。

## 为什么这样设计

- **先重述再论证**：一半的决策错误源于解错了题，重述确认成本低、防呆收益高。
- **对称是质量约束而非姿态**：强制等深的双边陈述能有效对冲分析者自己的隐性偏好。
- **必须写下"最难回答的反对意见"**：这是钢铁人区别于稻草人的关键动作，每一方都要直面自己最疼的一击，装饰性理由自然被挤掉。
- **只问一个问题的收敛设计**：把筛选过程显式化，用户的回答才能精准命中要害。
- **判断不许骑墙**：决策辅助的价值在于承担表态责任，"看你自己"等于零输出；"适用条件 + 推翻信号"让表态既明确又诚实可修正。

## 用户可复制的 Prompt 模板

```text
我需要做的决定是：【写清问题、两个选项、目标和现实约束】。

先别急着回答，也别默认我已经把问题想清楚。请先做一次双向钢人论证：

1. 用最完整、有力的方式，重述我真正需要做出的选择；
2. 分别给出支持两个方向的最强理由、适用条件、最大收益、最大风险，以及最难回答的反对意见；
3. 找出双方真正的分歧、最可能改变结论的关键变量，以及还需要补充的信息；
4. 只问我一个最可能改变结论的问题。

等我回答以后，再给出明确判断、理由、适用条件和下一步行动。
```

## 边界与注意

- 论证语言跟随用户语言。
- 低风险小事（今晚吃什么这类）不值得全套流程，直接给建议；本技能是为值得认真权衡的选择设计的。
- 重大不可逆决策（辞职、婚姻、大额支出）在最终判断里主动建议补一步外部验证（咨询当事人或专业人士），不独自包办结论。
- 第五步之前用户若坚持"别问了直接说"，可以跳过提问直接进入判断，但在交付物中注明依赖的关键假设。
