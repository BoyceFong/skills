# 双层解释法（Two-Level Explanation）

## 这个技能解决什么

人们学习陌生概念时最常见的失败模式是"**好像懂了**"：记住了一个生动的小学生类比，但机制是含糊的——换个场景就露馅。反之，只给专业术语的讲解又会让初学者一开始就掉线。

本技能的做法是：**对同一个概念分别讲两遍**——第一遍用生活语言和具体例子让零基础的人听懂"它大概是什么"，第二遍用准确术语讲清"它到底怎么运作、边界在哪、哪里容易错"；最后用术语对照表、易错点提示和 3 个自测问题收尾，把"理解了"变成可检验的。

你的角色是"解释者"，但要像一个好老师：先让听众上车，再带他们看引擎。

## 什么时候做

- 遇到完全听不懂的概念（数据库、网络安全、分布式系统、加密、算法等专业名词）。
- 想真正搞懂底层机制，而不只是记住一个比喻。
- 学习新领域时，用自测问题检验自己是否真的理解。
- Vibe Coding / 自行研究时碰到看不懂的名词或技术术语。
- 用户明确要求"双层解释""大白话 + 专业版""小白版 + 专家版"。

如果用户已经熟悉该概念、只需要一个简短定义，不要使用本技能，直接回答。

## 工作流程

### 第一步：确认要解释的概念

接收用户想学习的概念。如果概念本身含糊或有歧义（例如 "cache" 在不同语境下指不同东西），先确认用户是在什么上下文里遇到的；不确定时，选最常见的使用场景解释，并说明假设的语境。

### 第二步：第一层，小白版

用生活化的语言和**一个具体例子**，让完全没有基础的人也能听懂：

- 从用户熟悉的日常经验出发，建立第一印象；
- 只讲"它大概是什么、解决什么问题"，不讲术语细节；
- 例子要具体、贴近生活，并且**为第二层的机制埋下伏笔**（同一个例子在第二层会被"升级"成准确的说法）；
- 避免讲完就停——类比只是入口，不是终点。

### 第三步：第二层，专业版

使用准确术语，讲清三件事：

1. **核心机制**：它实际上是怎么运作的（数据结构、协议、流程、权衡等）；
2. **适用边界**：什么情况下它适用、什么情况下不适用（所有方案都有代价）；
3. **常见误解**：初学者（以及不少"好像懂了"的人）最容易错在哪里。

专业版默认面向有一定基础但初次接触该概念的读者：术语要准，但不要默认读者已经知道上下文里的其他专业概念；必要时用一句括号说明带过次要术语。

### 第四步：收尾三件套

按以下固定结构整理：

1. **小白说法与专业术语的对应关系** —— 用对照表把第一层的日常说法和第二层的术语一一对应，这是"两层"之间的桥。
2. **最容易理解错的地方** —— 指出 1–3 个最典型的理解偏差（包含但不限于第二层里的常见误解）。
3. **3 个用于检查是否真正理解的问题** —— 每个问题都应逼用户用机制（而非复述比喻）回答，例如"如果 X 不成立会怎样""在 Y 场景下这个方案会失效吗""用你自己的话向别人解释 Z"。不要问只靠记忆就能答的问题。

## 为什么这样设计

- **两层都要，缺一不可**：只有类比，用户记住的是故事而不是机制；只有术语，用户连门都进不来。两层合起来才构成完整理解。
- **同一例子贯穿两层**：如果小白版的例子在专业版里不能平滑升级成准确说法，说明这个类比本身是错的——这是个免费的自我校验。
- **必须讲适用边界**：真正的理解包括"它什么时候不适用"。只讲机制不讲边界，等于教人一把从不提醒"别用它拧螺丝"的锤子。
- **易错点单独列出**：误解是理解的负片。提前指出常见误区，比等用户踩坑后纠正便宜得多。
- **自测问题用机制而不是记忆**：能复述定义不等于理解。问题必须迫使读者在新场景中应用机制，才能区分"懂了"和"好像懂了"。
- **术语对照是桥梁**：对照表让用户以后看到专业术语时，能自动映射回已经建立的直觉，这是可迁移理解的关键。

## 用户可复制的 Prompt 模板

当用户想独立使用这套解释法（不依赖本技能自动触发）时，可以给他们这份模板：

```text
我想学习的是：【填写概念或问题】。

请分两层解释：

第一层，小白版。
用生活化的语言和一个具体例子，让完全没有基础的人也能听懂。

第二层，专业版。
使用准确术语，讲清核心机制、适用边界和常见误解。

最后请整理出：
1. 列出小白说法与专业术语的对应关系；
2. 我最容易理解错的地方；
3. 3 个用于检查我是否真正理解的问题。
```

## 边界与注意

- 语言跟随用户语言。
- 概念越抽象，越要保证小白版的例子具体、可触摸；不要用另一个抽象概念解释当前概念。
- 如果用户明确表示"我只要大白话，不要专业版"，或"我是专家，跳过小白版"，尊重对方，按需裁剪层级。
- 输出长度应匹配概念复杂度：简单概念两层都简短，复杂概念允许专业版更长，但小白版始终控制在"一次能读完"的长度。
