# My Skills

**English** · [中文](./README.md)

A personal skills collection for agents: original skills are version-controlled here, and well-made third-party skills are recorded (with their official source and install steps) in a recommendation manifest, so any agent that reads this repo knows exactly what to install.

## What this is

- **Original skills** — source vendored in `skills/<category>/<name>/`, editable and version-controlled.
- **Recommended third-party skills** — source NOT vendored; recorded in `recommended-skills.json` (machine-readable manifest) with their official source and install steps, installed from upstream when needed.

## Layout

```
.
├── skills/                       # Original skills (grouped by category, source lives here)
│   ├── engineering/
│   ├── learning/
│   └── quant/
├── recommended-skills.json       # Third-party recommendations (single source of truth)
├── recommended-skills.md         # Third-party recommendations (human-readable, generated)
├── scripts/render_recommended.py # Renders recommended-skills.md from the JSON
├── README.md / README_EN.md      # This doc (Chinese / English)
├── CLAUDE.md                     # Claude Code entry (thin @AGENTS.md shim; no real content here)
└── AGENTS.md                     # Conventions for all agents (single source of truth)
```

## Quick start

### Install original skills

Original skills live under `skills/<category>/<name>/` as source. Claude Code only auto-discovers the flat `~/.claude/skills/<name>/SKILL.md` layout, so each skill must be installed flat:

```bash
# e.g. install engineering/better-readme as ~/.claude/skills/better-readme
ln -s "$PWD/skills/engineering/better-readme" ~/.claude/skills/better-readme
```

Other agents install via their own skill mechanism; see [`AGENTS.md`](./AGENTS.md).

### Install recommended third-party skills

See [`recommended-skills.md`](./recommended-skills.md) (generated from `recommended-skills.json`; the generated list is currently in Chinese). Install each entry following its `install` field.

## Conventions

- **Original vs third-party**: original skill source is committed under `skills/`; third-party skills are never vendored — only `recommended-skills.json` is updated.
- **Single source of truth**: `recommended-skills.json` is authoritative; `recommended-skills.md` is generated by `scripts/render_recommended.py` — do not hand-edit.
- **Add/edit a recommendation**: edit `recommended-skills.json` → run `python3 scripts/render_recommended.py` to regenerate `recommended-skills.md`.

## What this is not

- Not a **runtime directory** for skills: `skills/` is source organization; each skill must be installed flat into the target agent's skills directory.
- Not a **mirror** of third-party skills: their source is not in this repo; only the upstream source is recorded in the manifest.

## Manifest field reference

Fields of each entry in `recommended-skills.json`:

| Field | Meaning |
| --- | --- |
| `name` | Unique skill id, matching the `SKILL.md` `name` |
| `title` | Human-readable name |
| `category` | Category (`engineering` / `learning` / `quant` / other) |
| `description` | One-line summary |
| `source` | Official source (repo URL) |
| `homepage` | Docs / homepage (optional) |
| `install` | Install method: `method` (`plugin` / `git` / `copy`) + relevant fields + optional `command` |
| `usage` | How / when to use it |
| `notes` | Notes (optional) |
