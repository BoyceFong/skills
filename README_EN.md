# My Skills

A personal collection of Claude Code skills, in two tiers:

- **Original skills**: source is vendored in `skills/<category>/<name>/`, editable and version-controlled here.
- **Recommended third-party skills**: source is NOT vendored; they are recorded in `recommended-skills.json` (machine-readable manifest) with their official source and install steps, and installed from upstream when needed.

## Layout

```
.
├── skills/                       # Original skills (grouped by category, source lives here)
│   ├── engineering/
│   ├── learning/
│   └── quant/
├── recommended-skills.json       # Third-party recommendations (single source of truth)
├── scripts/render_recommended.py # Renders the list below from the JSON
├── README.md                     # Chinese version of this file
├── README_EN.md                  # This file (English)
└── CLAUDE.md                     # Conventions & install instructions for agents
```

## Quick start

### Install original skills

Original skills live under `skills/<category>/<name>/` as source. Claude Code only auto-discovers the flat `~/.claude/skills/<name>/SKILL.md` layout, so each skill must be installed flat:

```bash
# e.g. install engineering/better-readme as ~/.claude/skills/better-readme
ln -s "$PWD/skills/engineering/better-readme" ~/.claude/skills/better-readme
```

### Install recommended third-party skills

See "Recommended third-party skills" below. The source of truth is `recommended-skills.json`; install each entry following its `install` field.

## Conventions

- **Original vs third-party**: original skill source is committed under `skills/`; third-party skills are never vendored — only `recommended-skills.json` is updated.
- **Single source of truth**: `recommended-skills.json` is authoritative; the list below is generated by `scripts/render_recommended.py` — do not hand-edit the list itself.
- **Add/edit a recommendation**: edit `recommended-skills.json` → run `python3 scripts/render_recommended.py` to regenerate README.md / README_EN.md.

## Manifest field reference

Fields of each entry in `recommended-skills.json`:

| Field | Meaning |
| --- | --- |
| `name` | Unique skill id, matching the `SKILL.md` `name` |
| `title` / `title_en` | Human-readable name (Chinese / English; `*_en` optional) |
| `category` | Category (`engineering` / `learning` / `quant` / other) |
| `description` / `description_en` | One-line summary |
| `source` | Official source (repo URL) |
| `homepage` | Docs / homepage (optional) |
| `install` | Install method: `method` (`plugin` / `git` / `copy`) + relevant fields + optional `command` |
| `usage` / `usage_en` | How / when to use it |
| `notes` / `notes_en` | Notes (optional) |
